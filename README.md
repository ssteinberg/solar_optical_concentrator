### Notes:
Implementation of the paper, <i>[Two-Mirror Compact System for Ideal Concentration of Diffuse Light](https://ssteinberg.xyz/2022/02/15/2mc-diffuse-light-concentrators/)</i>, by Shlomi Steinberg, Nandor Bokor, and Nir Davidson.

### To build:
```
cmake -H. -Bbuild
cd build
cmake --build .
```

### To plot:
Run the Jupyter Notebook, ```results.ipynb```.
